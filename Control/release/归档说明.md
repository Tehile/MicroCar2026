### 1.2 本轮（v2.4.0）改了什么

| 面 | 改动 |
|---|---|
| 课程层 | 上游 2.4.0 删除课程调参整层 ⇒ 参数表 **38 → 24 项**（生产标定 id 1–7 / 红外测量 22–32 / 电源监控 33–38，三组同页 115 同通道）；算参纯函数搬到上游 `host.host.api.calc`（`host.api` 仍导出） |
| 发车 | 新增 `MAZE RUN [BLIND\|RACE]`：`target` 只在请求体给，不给即 BLIND；不认 `target` 的老上游当场 **400**（不冒成 500） |
| 2.3.0 通道 | 统一帧 **39 → 49**：`frontNear`/`frontFar`/`frontBoth`、`spurtMode`/`spurtFlag`/`goOrBack`/`spurtTestFlag`/`objectGoToFlag`/`goaheadnum`/`fastwayCount90` |
| 能力位 | 修 `_probe_features()` 里 `unified` 写死 39 通道导致的**静默失效**（升 2.3.0 后变 False 且无判据会红） |
| 界面 | 小车控制 **四卡 → 三卡**：① 实时状态与参数设定（含运动控制、校准例程两个区块）② 无记忆走迷宫 ③ 比赛（新建） |
| 判据 | 新增 **I31**；I16 改「24 项三组、课程组必须为 0」；I22/I27 不再写死通道数；B24 卡片数 4→3；B30 三模块；B.exp 改两支 |

## 4. 怎么用

```bash
PY="C:/Users/liuru/.conda/envs/general_env/python.exe"
export NO_PROXY="127.0.0.1,localhost" no_proxy="127.0.0.1,localhost"   # 代理会劫持回环
```

浏览器端到端：先起 `app.py`，再 `$PY tools/browser_check.py --no-fake-cam`。

## 6. 归档纪律（下次照这个来）

1. **先全绿再归档**：四条判据（`preflight` / `drill --sim` / `browser_check` / `check_iface_table`）
   顺序复跑必须 0 FAIL（I9 除外，属上游侧）。
2. **说明先行**：归档说明（本文件）与记忆/日志**先写完、先提交**，再谈打包 —— 否则包里是旧版。
3. **本版形态 = 源码提交，不打 zip**（按用户要求）。
4. **收工清场**：停 8770；清 `records/maze/*.maze.json`、测试 `sessions/`、`.tmp/`、`__pycache__`；
   确认 **8770 空闲**。
5. **提交格式**：`[feat] Control: <一句话>`，正文分条列改动，语言精炼、不口语化。
6. **不动上游**：上游源码改动一律不提交（本仓库内含上游，但本层只消费）。
