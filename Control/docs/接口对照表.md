# Control 接口对照表（Control 端点 ↔ 上游方法）

> 这份表的存在意义只有一个：**防漂移**。
>
> 上游两个仓库各有自己的取证体系，我们不碰它们的源码（判据 I9）。代价是：上游哪天把
> `ArucoLocator.run_session()` 改名了，Control 会在运行时才炸，而且只在现场那一页才炸。
> 所以这里把「每个端点是靠哪个上游方法撑起来的」写成一张**能被机器读**的表，
> 并用 `python tools/check_iface_table.py` 一条命令同时校验三件事：
>
> 1. 表里写到的每个上游符号**真的存在**（改名/删除立刻现形）；
> 2. `routes.py` 里注册的每个端点**都在表里有记录**（新增端点忘了登记会报错）；
> 3. `docs/上位机整合设计方案.md` 的附录 A 与这份表一致（只有指向，不重复内容）。
>
> **改上游之后先跑它，不要靠眼睛。**

上游路径（相对 `Control/`，见 `config.yaml` 的 `paths`）：

| 代号 | 仓库 | 路径 |
|---|---|---|
| A | `RemoteControl` | `../RemoteControl/host`（包名 `host`） |
| C | `Auto Locate` | `../Auto Locate`（模块 `aruco_locator`） |

`—` 表示这一步是 Control 自己的逻辑（读缓存、编会话目录、做统计），不经过上游。

## 1d. 统一帧遥测与迷宫状态机（模块 A，上游 **2.0.0**）

> ⚠️ **本节的形态是 2.0.0「传输模式重构」之后的**。它**取代了** 1.5.0 的「组测发送 `SNAP`」
> 与 1.5.5 的「三通道迷宫回传」。上游明确"协议整体替换、不做兼容层"，所以本层
> **没有 `_v2` 端点、没有弃用期**：旧端点一律 404（判据 I22/I23 负向验证）。
>
> **只有一条流**：`TYPE_UNIFIED`（53 B = 8 B 开销 + **45 B 载荷**）/ **拉取模式** /
> 解码后 **39 个扁平通道**。四路红外**ADC 与 mm 双传**（非线性映射，上位机不便复算）、
> 电池给 mV（线性映射且分压标定在设备端，所以不传 ADC）、完整迷宫状态机就在帧里。
> ⚠️ 帧率**由上位机的拉取节奏决定**（真机 4.4~6.5 Hz），`UNIFIED_HZ = 217.0` 只是
> 协议常量、**不代表实际帧率** —— 见下方 2.1.0 说明。
>
> **为什么删除 `SNAP` / `SCOPE`**（上游设计方案 §6）：两者存在的唯一理由是"物理速率不足"
> （旧链路 152 B/s，只能"实时看状态 / 停车拉数据"）。改自时钟发送后，**每一帧都是全量快照**，
> "实验期间的数据"本来就在主机内存里 ⇒ `SNAP` 的"静默一问一答"与 `SCOPE` 的"停车后整块回传"
> 都不再需要。代价是失去"零常驻带宽地看一个瞬时值"—— 而那个代价**只剩一种付费方式了**。
>
> **迷宫状态机回传**（`LESSON_Blind8`）：观测层整个放在固件 `HARDWARE/link.c`，
> **不在 maze/state/lesson/motion 里插一行钩子** —— 只读已公开的 `mazeState` / `wallSns` /
> `motionCtrl.task`，所以"回传的状态"与"代码里的状态"同源，且关掉本模块行为逐字不变。
> 状态量**全在统一帧里**；"它刚才识别到了什么"由**主机差分相邻帧**得到（`MAZE EV` 已删除）。

> 视差全部不生效，结果是一堆无效帧，然后被误判成"这个视频不行"。

## 7. 明确**不**映射到上游的端点（本层自研）

这些没有对应的上游方法，理由写在「说明」里 —— 列出来是为了防止有人误以为漏了：

| 端点 | 为什么属于本层 |
|---|---|
| `health` / `caps` / `config` / `paths` / `upstream` / `logs/tail` | 「整合层」这个概念只在这里存在，三个上游各自都不知道有别人 |
| `clock/*` | 统一时钟是整合层引入的（墙钟为主时钟），上游没有跨机时间基 |
| `session/*` | 把多路产物收进**一个**会话目录、一条时间线，是整合层的核心职责 |
| `arena`（只在 `health.arena`） | 8×8 场地的**画图几何**；坐标换算的契约现在归上游 Auto Locate 的配置 |
| `video/*` | 子进程生命周期、产物读取、时间轴自洽校验都是本层的编排职责；上游只负责给一份 session.json |
