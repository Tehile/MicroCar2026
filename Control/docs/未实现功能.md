## 2. 未接通项

### 2.1 迷宫结构解析（定位）

**为什么列在这里**：上游 Auto Locate 已经把算法做出来了 —— 仓库根目录的独立脚本
`maze_extract.py`，核心接口：

```python
extract_maze(frame_bgr, H_img2field, cfg) -> (Maze, 正射图, 红色掩码)
```

它从**红色墙线**解出 8×8 迷宫的墙结构，并输出邻接图与结构示意图。

**卡在哪一步**：本层手上没有**彩色帧**。

- PhoneCamera 的**交付道**落盘的是**原始 Y 平面**（灰度），Control 的 `decode_y()`
  只是把它铺成三通道；那张图里没有红色 ⇒ `extract_maze` 解不出墙。
- 彩色只存在于**实时道**（`capture_mode=live`），而实时道**不落盘**（"只看不留"）。

**因此缺的是**：一个"彩色帧的落盘来源"。这属于上游能力，不在整合层伪造。

**接通后要做的**（留给后续）：

1. 拿到彩色帧的落盘路径 / 或一条"取一帧彩色"的接口；
2. 用现有的 `locate()` 先在**同一帧**上解出场系单应 `H_img2field`
   （`maze_extract` 自己不检测标记，它**要求调用方给 H**）；
3. 新增一个端点把 `extract_maze` 的输出转成 PNG + 邻接 JSON 给前端；
4. 前端把结构图（`render_structure()` 的白底黑墙图）显示出来。

**注意**：`maze_extract.py` 是**独立脚本**，**不在** `aruco_locator` 包里，
`__all__` 未导出（上游明确"v1.x 接口保持冻结"）。消费它要单独 `import` 并把上游根目录
加进 `sys.path`；**不得**把它并进包，也不得改它的源码。

### 2.2 综合运动（推迟）

用户已明确"综合的页面不急着完成"。它当前就是原有的**两栏九页**（①场地 ②采集 ③参数
④标定 ⑤发车 ⑥实验 ⑦波形 ⑧调试台 ⑨数据），功能完整、继续可用；
将来若要按子系统重排，再单独决策。

**上游没有的东西**（不要假装有）：

- `mc.move` **没有 `turn(deg)`**（转向是按 cm/s + ms 的开环定长）；**没有 `rear`**（后退用负速度）。
- `mc` **没有 `caps()`**（能力协商未实现）。⚠️ 2026-10-05 起 `registry.API_VERSION` **可信**
  （上游每次都改，已到 2.2.1），但 `host.__version__` 停在 2.1.0 ⇒ 两者**不一致是上游的既有状况**；
  本层仍以 `API_VERSION` 为准并**一律走能力探测**，不靠版本号判能力。
- ~~`mc.maze` **没有"停止跑迷宫"**~~ ⇒ **2026-10-05 已被上游推翻**（2.1.1 新增 `MAZE STOP`）。
  现在的实情分两层，都要知道：
  · **`MAZE STOP`（【收车】）存在**：停车 + 复位发车状态 + 解锁急停 ⇒ 不必断电即可再发车；
  · **但车在运动时它不可靠**：它只置一个"请退出"标志（`linkMazeAbort`），而标志的检查在
    `LESSON_Blind8()` 的 `while(1)` **顶部**，主循环却有 30 余处**非协作式阻塞等待**
    （等的是编码器里程这类**物理进度**）⇒ 车在运动时程序正卡在那些循环内部，标志轮不到。
    真机实测：回 `OK` 但 `mazeTask` 仍 `SEARCH`。
  · ⇒ **可靠收车手段是 `MCU RESET`（【救援】，2.2.0）** —— 整机软复位，BSS 清零把发车状态
    一起清掉。代价是**复位不复位物理位置**（发车前必须人工把车放回起点角），且复位后
    约 3 s 才有新遥测帧。由 **I28** 守（含"收车后能再发车"与"急停中发车回 ERR_ESTOP"）。
- **课程参数的值读不回来**（2.0.0）：固件 `GET ALL` / `GET <name>` 只查**生产表**（24 项），
  课程 14 项一律回 `ERR_NAME`；**写侧**（`SET`/`SETQ`）仍通。所以界面上课程组标着
  「值读不到，可写」，SAVE 时要**先把新值填进输入框**。这不是本层漏做，是固件侧的读侧缺口。
- **没有"事后回传课程日志"**（2.0.0）：`SCOPE`/`DUMP` 整套删除，曲线只在 `lesson/run`
  期间就地捕获。所以那个按钮**已删除**，路由也明确报错而不是返回空数组。
