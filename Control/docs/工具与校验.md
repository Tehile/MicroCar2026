# Control · 工具与校验

> 六个脚本，回答三个问题：**能不能跑** / **跑起来对不对** / **文档要不要重导出**。
> 全部用 `general_env` 里的 Python 跑（`Auto Locate` 明令不得在别的环境装包）。

```bash
PY="C:/Users/liuru/.conda/envs/general_env/python.exe"
export NO_PROXY="127.0.0.1,localhost"      # 本机端点必须绕过代理，否则请求会打去外网
```

## 2. `preflight.py` —— 启动前自检

> 按顺序把"会让人白折腾半小时"的事先排掉。每一项输出三段：**检查了什么 / 结论 /
> 不对时怎么改**。

```bash
$PY tools/preflight.py            # 全量
$PY tools/preflight.py --quick    # 跳过网络与 git（离线环境）
```

实际有 **11 个检查小节**，顺序按致命性排（少了前者就什么都跑不了）：

| # | 小节 | 查什么 |
|---|---|---|
| 1 | 配置 | `config.yaml` 能不能载入、键有没有写错 |
| 2 | 依赖 | 整合层固定用 `general_env`，依赖齐不齐 |
| 3 | 上游仓库路径 | `RemoteControl` / `Auto Locate` 找得到吗 |
| 4 | 上游可 import | **只 import，不改它们** |
| 5 | 判据 **I1** | 不许引入 `PySide6` / `pyqtgraph` |
| 6 | 判据 **I9** | 上游仓库的工作区必须干净 |
| 7 | 串口 | **串口是独占的**，被占就没有第二个能连 |
| 8 | 视频复盘 | 离线链路（视频文件 → Auto Locate 会话解析） |
| 9 | 会话根目录可写 | 落盘的目录有没有写权限 |
| 10 | Control 自己的端口 | 8770 有没有被占 |
| 11 | 大方向冻结 | 宗旨与布局不得改动 |

第 8 节（视频复盘）在 `--quick` 下会跳过。

## 3. `drill.py` —— 端到端演练 + 判据

这是本项目的承重判据集。**每条判据都编号（`I*`），既可以自动跑也能单独被引述**。

```bash
$PY tools/drill.py                # 起临时服务，跑完整链路
$PY tools/drill.py --sim          # 额外起上游鼠标模拟器（有真数据）
$PY tools/drill.py --port 8899    # 8770 被占时换端口
```

### 3.1 编号现状（2026-10-26 第三次核对）

实际存在的编号 **56 个**：

```
I1  I2  I3  I4  I5  I6      I9  I10     I12           I15 I16 I17 I18 I19
I20 I21 I22 I23 I24     I27 I28 I29 I30 I31 I32 I33 I34 I35 I36 I37 I38 I39
I40 I41 I42 I43 I44 I45 I46 I47     I49 I50 I51 I52 I53 I54 I55 I56 I57 I58 I59
I60 I61 I62 I63 I64
```

⚠️ **编号不连续是常态，不是漏写**：`I7 I8 I11 I13 I14 I25 I26 I48` 这些随相关功能
下线而被移除，编号**不留补丁、不重号**（改名连判据一起改，见记忆中的相关纪律）。
所以"缺号"不代表"还没做"。

`I56`~`I59` 是改版四十一新加的（帧率口径 / 判死处置 / 复核时机 / PING 退避），
全在 `drill.py` 的 `0e` 段，**纯内存 + 假上游**，不依赖模拟器 —— 因为这三处
改的正是"没数据也照常显示"的静默错，读数字验不出来。

`I60`~`I62` 是改版四十二新加的，同样在 `0e` 段：
- **I60** 命令占链路（`_cmd_inflight` / 上游 `_suspends>0`）时**一次都不复核**，
  且 `_cmd_exit` 把"停帧计时"挪到放手那一刻；
- **I61** 放手时清 `upstream:link_lost`（自己 suspend 出来的假阳性）、
  **保留** `cmd_timeout:*`（真没问出结果）；
- **I62** 拉取自愈：想要帧+没在跑 ⇒ 补一次；**人明确停了 ⇒ 一条开流命令都不许发**；
  命令刚放手不补；补满 2 次停手；帧回来计数归零。

`I63`/`I64` 是改版四十三新加的，同样在 `0e` 段：
- **I63** 动作码表（`/caps` 的 `motions`）必须**盖住上游全部 38 项**、每项都有中文短名、
  `motion_stopped` 恰为 `{0,5}`（1/12/101 明确不在）。⚠️ 上游码表取不到时
  "空集合 ⊆ 任何集合"会让"覆盖上游"**恒真**，所以那种情况给 SKIP 并写明，不硬过。
- **I64** 收车：帧龄 9 s（没帧源）⇒ `waited=false`、`reliable=None`、**耗时 <1 s**；
  帧龄 50 ms ⇒ 仍走等待分支。两个方向缺一不可（详见 §11.43）。

### 3.2 `--sim` 的边界

- **不加 `--sim`**：跑不了需要活链路的那些（`I15`~`I17`、`I22`、`I23`、`I27`、`I28`、
  `I30`~`I33` 等）⇒ **这些会跳过**，不是通过。
- **加 `--sim`**：模拟器会破坏确定性相关的验证 ⇒ 相关项标 **SKIP**，**不硬过**。
- 8770 已有旧实例时会自动改用别的端口。

一句话：**看汇总要同时看 `PASS` 数和 `SKIP` 清单**，只看 PASS 数会被蒙。

## 4. `browser_check.py` —— 无头浏览器实测

> **九个页面真渲染 + 接缝真的接上了。** 用 CDP（`aiohttp` 就够了），不引入 Playwright
> —— 本机本来就有 Chrome，少一个 ~150 MB 依赖，多一条能随时重跑的命令。

```bash
$PY tools/browser_check.py                    # 默认连 http://127.0.0.1:8770
$PY tools/browser_check.py --sim              # 自己起服务 + 模拟器
$PY tools/browser_check.py --only V7          # 只跑某一组
```

### 4.1 核心是 `V6` —— 验"接缝真的接上了"

**要验的不是"界面把数据显示对了"，而是"点了按钮，请求到底有没有发出去"**。
做法：在页面里注入 `fetch` 记录器，点【应用】把每批帧数设成 3，然后去请求记录里
**找** `POST /api/v1/mouse/stream/batch`。找不到就是没接上 ——
而界面上一句"已下发"是**本地 toast，跟网络毫无关系**。

### 4.2 负向判据 `V5` —— 不许假绿

> **设备没连上时，界面不许说连上了。** 假"已连接"会让人以为可以去发车。

⚠️ `--sim` 与不带 `--sim` 两种情况**断言方向相反** —— 双向都点才叫判据。

### 4.3 组清单（V0 ~ V20）

| 组 | 验什么 | 判不了时怎么办 |
|---|---|---|
| V0~V4 | 页面/DOM/资源/错误的基本命题 | 直接 FAIL |
| **V5** | **设备连接状态不许与后端矛盾**（假绿/假红） | 双向都跑 |
| **V6** | **接缝**：注入 fetch 记录器抓真请求 | SKIP 需说明原因 |
| **V7** | 记录页 + **真数据**；后端给 `null` 账本时界面必须显示「判不了」而不是「差 N 帧」 | 无记录/非真机 ⇒ SKIP（**不是失败**） |
| V8 | — | — |
| **V9** | 参数端点：参数 41 项四组，派生值只读；鼠未连 ⇒ 端点 409、界面理应没表 | SKIP 需说明原因 |
| V10 | 假端口不许说已连接 | — |
| V11 | **拉取按页开关**：要帧的页才开门拉（`overview/live/params/maint`），其余页不拉 | 未连设备 ⇒ SKIP |
| V12 | 实时图（尺寸 = 设备 mazetype，且 4 s 内帧数在涨） | 未连设备 ⇒ SKIP |
| V13 / V14 | — | — |
| V15 | 清空动作 | 未连设备 ⇒ SKIP |
| V16 | 「已保存 · 名 · N 帧」**是中间态**：保存后出现过，5 s 后必须回「停止并保存」 | 造不出记录 ⇒ SKIP（并写原因） |
| V17 | 比赛页拉取**半手动**：进页开一次、手动停后**把 8 s 豁免清零**再等 4.5 s 仍是停 | 未连设备 ⇒ SKIP |
| V18 | **发车状态 vs 旧帧**：钉住窗口内旧帧（**动作码=直行**）不许把 `running` 翻成 true；窗口过后**同一帧**必须说了算（且钉已清） | 不需要硬件（直接驱动判定函数）；取不到函数 ⇒ SKIP |
| V19 | 收车**点击即反馈**：点下去 300 ms 内按钮含「收车中」+ disabled、发车键 disabled、`_pend` 存在；确认后（动作码空闲）回「收车」且**拉取已停** | 未连设备 ⇒ SKIP（按钮本来就禁用） |
| V20 | **断开归零**：喂 `connected:false` 的 health ⇒ `hz2=null`、曲线 0 点、动作码 0、`running=false`、`telRxAt=0`、`posX=null`、迷宫图被清；界面帧率写 `0` | 断开前就没有帧率 ⇒ SKIP（判不了"清零"） |

⚠️ V16 只验"回落"会假绿（"从来没显示过"也通过），所以它验**两段**。
⚠️ V17 必须先把 `LIVE.pullOffAt` 清零：否则 8 s 内的静默是"人工停豁免"给的，
验不出 `race` 是否还在 `GUARD_PULL` 里 —— 那样这条永远假绿。
⚠️ V18 两个方向缺一不可：只验前半会放过"钉不过期"（**永远收不了车**）；
只验后半会放过"根本没钉"（**改版四十一的那个 bug**）。它验的是
`C.applyRunning()` 这个判定函数本身，不走真机发车 —— 那条时序真机未必复现。
⚠️ V19 把 `C.act` 打桩成"1.2 s 后才 resolve"（**只桩网络，不桩界面**）：
真机上命令可能 30 ms 就回来，300 ms 时早已进观察窗 ⇒ 那样这条会飘。
⚠️ V20 必须**先塞一张假迷宫图**再喂 `connected:false`：本来就 `null` 的话，
"清空"这条恒真（假绿）。（这条是老坑，与 V17 的"豁免清零"同族。）

> 标"—"的是本项目当前未被 AI 逐条读透的组；**宁可留白也不猜**（下游自证原则）。
> 要看某组的确切命题，直接读 `tools/browser_check.py` 里对应的 `record("Vn", …)` 及其上方注释。

⚠️ **常见误会**：`--port` 是"连已有服务"，**不会自己起**。要验新后端必须自己先起一个
实例（用完关掉），否则连到的还是旧代码。

## 5. `check_iface_table.py` —— 防文档漂移

检查三件事：

1. **上游符号真的存在** —— `接口对照表.md` 里写的 `HostLink.ledger` 这类裸名，
   逐个在上游里核对；
2. **本层端点真的存在** —— 表里列的路由在 `routes.py` 里能找到；
3. **两边一致** —— 端点 ↔ 上游方法的对应关系与实现同步。

上游协议版本一变（PROTO 9 → 10 这类），这张表是最先过时的地方，所以要在 CI 习惯里跑。

## 6. `neg_i30.py` —— 判据的变异验证

> 纪律：**一道从没红过的闸不算闸。**

守的是"两条来路同一个纪元"。做法是把修复撤掉再跑一遍：

- **A（现状）**：`_reset_epoch()` 清环 + 换差分器 + 零点交给发车后第一帧；
- **B（旧行为）**：只挪零点，不清环也不换差分器（就是当年修掉的那个 bug）。

要看的就一件事：B 里会不会出现**负 `t_ms`**（上一段/发车前的决策残留在新纪元里），
而 A 里不会。实测 **A 0 条 / B 11 条** —— 两者一样就说明这道闸根本没咬住。

⚠️ 它**特意保留在仓库里**（不像临时脚本那样用完删）：差分/纪元逻辑再动时，
重跑一次就知道闸还有没有牙。

## 7. `build_doc_html.py` —— 文档导出

```bash
$PY tools/build_doc_html.py              # 渲染 docs/ 下全部 .md
$PY tools/build_doc_html.py docs/x.md    # 只渲染指定文件
```

产物是自包含的暗色 HTML（无外部依赖、无 CDN、可离线打开）。

⚠️ **改了 `docs/*.md` 之后必须重跑一次**，否则 `.html` 是旧的 —— 离线交付时
给人的是 html，它就代表"最新状态"。
