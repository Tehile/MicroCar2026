# V3：终点掉头后的起步与首次转弯衔接

工程名称：`code_competition_终点掉头起步衔接修复_V3_20261024`。

本版从不带 V2 补偿的 `code_competition_V字路按搜索_20261022` 重新复制。源工程 264 个文件 SHA256 逐项核对无变化，V2 的源码与工程配置也未改动。保留无 45° 冲刺、V 字路搜索走法及 20261022 首段定位/90° 衔接。

**默认选择 V3_0mm。这里的 0 mm 已包含终点起步衔接修复；它表示基础起步段之外不再加距离，不是关闭修复。四档参数只调整终点掉头后的起步段，不作用于普通左转。**

## 修复内容与范围

原程序 `mouseTurnback()` 在终点会跳过 `after180turn()`，随后仍改变朝向、推进坐标、清零 `track`。如果回程相邻格立即左转，车体只等待普通左转的约 7 mm 就开始转弯，缺少进入该动作参考位置的起步段。

本次生产代码只修改 `UTILITY/utility.c`：新增内部函数 `goalDepartureAfterTurnback()`，在普通搜索/回程、当前位置等于终点且冲刺复用状态未激活时，按以下顺序离开终点：

1. 沿用原 `before180turn()` 的定位、`taskturnaround()` 的掉头和地图保存。
2. 起步目标距离采用 `max(accdistance, (long)disbf180 - 35) + GOAL_DEPARTURE_EXTRA_MM`。
3. 复用原 `taskacc()`，然后用现有 `SMARTSTRAIGHT` 以搜索转弯速度完成剩余段；默认加速段为 40 mm，已计入总距离，不会再重复加一次。
4. 起步结束后才更新朝向、推进坐标并采墙，再清零 `track`，交给原普通直行或 90° 转弯逻辑。

当前有前墙分支 `disbf180=90`，所以基础起步目标为 55 mm。无前墙时沿用原制动距离关系，并确保总起步距离不小于加速段，避免负数转成无符号长距离。侧墙校准的额外原地转动没有加入这个新起步段。

普通 `before90turn()`、左/右转曲线与出口补偿、普通直行状态值和 20 mm 衔接、红外标定、速度/PID、非终点掉头、入口专用掉头及冲刺执行逻辑均保持源版。新逻辑没有增加全局 RAM；动作编号和 Flash 保存格式不变。

55 mm 是复用当前代码几何关系得到的初始控制目标，仍需真机确认。红外标定和掉头姿态本次沿用源版，没有据软件检查认定实车必然不会撞墙。

| Target | 终点起步额外量 | 有前墙时起步总目标（含加速段） | 随后立即左转的入弯门限（自掉头完成计） | HEX 输出 |

1. 在 Keil Target 下拉列表选择 `V3_0mm`、`V3_2mm`、`V3_4mm` 或 `V3_6mm`。
2. 点击 **Project → Rebuild all target files**，确认当前 Target 正确，输出为 **0 Error(s)**。
3. 连接自己的下载器，核对原下载设置，点击 **Flash → Download**。切换档位后重复 Rebuild 和 Download。

`USER/TEST.hex` 是 0 mm 兼容副本；各 Target 实际输出以上表为准。集中交付的四份 HEX 与 AXF 在 `固件_V3_终点掉头起步_20261024`，文件名为 `TEST_V3_终点起步附加0mm_20261024.hex` 等四档。复制来的带 20261022 名称的旧固件作为历史文件保留，本次测试请选择 V3 文件。
