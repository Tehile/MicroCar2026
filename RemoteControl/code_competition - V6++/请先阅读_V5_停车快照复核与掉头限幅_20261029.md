## 本次改变了什么

1. 在原来灯1、2与灯3、4的前方过近保护入口，先冻结触发快照，再立即把左右轮目标设为0。保持控制中断和测距工作，不直接进入休眠。
2. 最多复核500个控制周期（名义约0.5秒）。只按新红外采样计数；左右轮反馈均在 -2 到 +2 之间，且两个前方查表距离均不小于30、不大于249，平均值与两路一致，连续20次满足后才允许恢复，停轮总时长至少50个周期。输出触发数据后重新积累确认窗口，输出期间的读数不直接当作确认通过。
3. 成功恢复时保留原编码器基准、真实刹停行程、坐标、朝向和上一动作。不会重新清零一格里程，也不会凭空提交下一格。
4. 持续近墙、数据不恢复、没有新采样、轮子未停稳或原有急停等情况，不放行。保留原来的灯1、2或灯3、4保护停车。没有加入盲目前进、自动倒车或强行掉头。
5. 只在普通搜索的非终点 `mouseTurnback()` 接近前墙阶段，把侧墙纠偏限制在基础速度的三分之一以内。默认基础速度30时，两轮目标限制在20～40，避免侧墙误差使一轮反转。该阶段原来短暂使用80直行速度的衔接改为保持搜索慢速；接近前墙后的原有定位、180°曲线及普通出发流程保留。

终点4mm起步、普通90°曲线、原来的全局速度/PID/红外标定、侧墙断墙里程修正、无45°冲刺和V字路搜索走法保留。特殊起点掉头、终点掉头和冲刺不启用此次普通死路限幅。没有加入上位机协议。

注意：代码中的10、20、30、249等红外距离是原工程的查表坐标，不能直接等同于尺量毫米。本次不宣称已经修复红外光学误读本身；记录用于区分采集异常、换算异常和真实近墙。

## 记录在哪里，如何读取

全局调试变量：`v5_diag`，在当前固件中占256字节。

| 字段 | 含义 |
|---|---|
| magic | 0x56354431表示已有有效事件 |
| events / recovered / persistent | 本次上电的触发次数、恢复次数、未放行次数 |
| source | 1：原有侧墙直行保护；2：原无侧墙直行保护 |
| result | 0：正在复核；1：恢复；2：持续异常；3：原有急停/休眠/任务改变 |
| first | 本次上电首次触发瞬间，后续触发不覆盖 |
| last | 最近一次触发瞬间 |
| recheck | 最近一次停轮复核快照，结束时更新为最后确认数据 |

三份快照包括：新采样序号、相对/绝对里程、两路前方距离及平均值、两侧距离、四路滤波后ADC、前方两路发射开关差分ADC（滤波前）、目标/实际轮速、陀螺仪角度、任务编号、上一动作、坐标、朝向与墙标志。取触发快照时短暂屏蔽中断，防止混入不同采样的数据。

读取方式：

- 已连接原比赛串口时，用普通串口助手 **115200、8N1** 保存文本即可。轮子停稳后自动输出 `V5_STOP`、`V5_TRIGGER`、`V5_RECHECK`。`result=0` 是复核开始阶段的数据，不代表永久故障；如果持续异常，随后还会输出 `result=2/3` 的最终记录，再进入原LED保护。短暂误报是否已恢复，也可从实际继续行进和 `recovered` 计数确认。
- Keil 加载对应 V5 AXF 后，在不复位、不重新下载的连接调试会话中查看 Watch 的 `v5_diag`，展开 `first`、`last`、`recheck`。默认“启动调试”可能复位目标，应先配置连接现有运行目标；不熟悉时优先保存串口文本。
- 快照保存在 RAM，**复位、断电、重新烧录会丢失**。不在运动中擦写新Flash页，也不改变地图、路径或标定的Flash格式。

如果再次在空旷前方停车，优先提供 `V5_TRIGGER` 和 `V5_RECHECK` 全部行：ADC异常偏强且查表距离过近，优先检查红外采集/反射；ADC正常但查表距离异常，优先检查标定/换算；两路距离与平均值不一致，则检查数据更新或数据完整性。

## RAM与栈

原 V3 的20KB RAM已全部占用，原栈仅512字节。V5将旧行车记录容量由1200条减为1136条，腾出512字节，其中256字节用于快照，另256字节将栈增至768字节。原记录内容与格式不变，容量减少64条（名义约0.128秒）。总RAM仍为20480字节，不覆盖路径动作数组。

Keil静态调用图估算：搜索诊断路径加一次SysTick和硬件异常帧为552字节；原初始化路径同样计入中断为712字节，均低于768。该值是静态估算，不能替代实机测量。

## 实车验收顺序

1. 使用V5_4mm，与V3使用同一套标定和地图，先确认正常搜索、到终点后起步及首次左转；重点检查连续左转、短直线接左转。
2. 重复图片中的回程结构，观察蓝叉抖动是否减少、绿叉是否还停车；建议同一方向连续测试10次，再测试镜像方向。保存所有V5诊断文本，并记录是否短暂停轮后自行恢复。
3. 若仍灯3、4闪烁，不先重新上电，先保留数据。持续异常仍停车是有意保留的保护，不应直接删除阈值来强行放行。
4. 在安全的固定支架条件下验证持续近墙保护，不通过故意高速撞墙测试。真死路应仍能完成原来的定位与掉头。
5. 搜索稳定后，再检查无45°冲刺和V字路普通搜索绕行；四档目标值仅用于终点起步，不用于调节此次保护阈值。
