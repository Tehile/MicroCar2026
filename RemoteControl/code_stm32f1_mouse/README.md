# Code_STM32F1_Mouse 电脑鼠竞赛程序

基于 **STM32F103RB** 的电脑鼠(迷宫探索)竞赛单片机程序。程序自动完成 16×16 全迷宫的**探索建图、最优路径规划与高速冲刺**,适用于"电脑鼠走迷宫"竞赛项目与教学参考。

## 功能特性

- **全迷宫探索建图** —— 6 种贴墙法则(右手/左手/右左/左右/中右/中左)+ 中心法则组合,自动完成未知迷宫探索与墙图构建
- **洪水填充最短路** —— DFS 等高图 + BFS 逐层最短距离(双栈),支撑路径回溯与岔路决策
- **8/4 方向最优路径** —— 允许 45° 斜切的 8 方向最短路,与纯 90° 的 4 方向最短路,输出紧凑的相对转向动作序列
- **45°/90° 双冲刺模式** —— 斜线冲刺(45°)与垂直冲刺(90°),L/M/H 三档速度,转弯前睁眼/闭眼直线校正
- **实时运动控制** —— SysTick 1ms 中断完成陀螺积分、编码器里程、红外测距、运动状态机与电机 PID 闭环
- **Flash 自存数据** —— 迷宫墙图、冲刺路径、红外标定、陀螺零偏等运行数据固化保存,断电不丢失

## 硬件平台

| 项目 | 参数 |
|------|------|
| 主控芯片 | STM32F103RB(Cortex-M3,128KB Flash / 20KB RAM) |
| 主频 | 72 MHz(8MHz HSE 晶振 ×9 PLL) |
| 系统时基 | SysTick 1ms 中断(运动控制实时核心) |

**外设用途**

| 外设 | 用途 |
|------|------|
| TIM1 | 微秒/毫秒延时基准(1MHz) |
| TIM4 | 四路电机 PWM(PB6–PB9) |
| TIM2 / TIM3 | 左/右轮正交编码器输入 |
| ADC1 | 4 路红外测距 + 陀螺角速率 + 电池电压 |
| USART1 | 调试串口 + printf 重定向(115200-8-N-1) |

**传感器**

| 传感器 | 说明 |
|--------|------|
| 红外测距 ×4 | 前左/前右/左/右,一维卡尔曼滤波 + 4×250 点标定查表 |
| 模拟陀螺仪 | 角速率梯形积分得到航向角 |
| 光电编码器 ×2 | 里程计与角度融合 |

## 编译烧录

### 工具链

- Keil MDK-ARM Plus **V5.24+**(`uAC6=0`,ARMCC V5.06 update 5 build 528)
- 器件支持包 **Keil.STM32F1xx_DFP.2.0.0**

### 工程配置

- 打开工程文件 `USER/Mouse.uvprojx`,目标器件 **STM32F103RB**
- 构建宏:`STM32F10X_MD`、`USE_STDPERIPH_DRIVE`
- Include 路径:`..\APP;..\HARDWARE;..\USER;..\STRATEGY;..\MOTION`
- 编译输出 Intel HEX 镜像 `USER/Object/Mouse.hex`

### 烧录

- 调试/烧录器:**J-Link 板载**(J-Link ARM-OB STM32),**SWD** 接口 5MHz
- 烧录算法:`STM32F10x_128.FLM`(128KB)
- 内存布局:代码区限制在前 **88KB**(页 0–87),`0x08016000` 之后整段为固件自存数据区

### 内存占用(当前构建)

| 项目 | 大小 |
|------|------|
| RO(代码 + 常量) | 73.02 KB |
| ROM(镜像) | 74.59 KB |
| RAM(RW 数据) | 19.56 KB |

## 使用方法

上电后**短按**按键循环切换档位(LED 显示档位号),**长按(>600ms)**确认进入;不按键则停在档 0。档 2–8 为标定菜单,进入后不返回,靠断电复位退出。

| 档位 | 功能 |
|------|------|
| 0 / 1 | 进入主流程(读地图 → 选速档 → 迷宫搜索 → 冲刺) |
| 2 | 擦除红外标定数据 |
| 3 | 自动标定陀螺仪零点 |
| 4 | 红外自检 / 前向对正测试 |
| 5 | 串口打印传感器数据 |
| 6 | 红外距离标定 |
| 7 | 串口打印迷宫与路径数据 |
| 8 | 休眠(LED 流水灯) |
