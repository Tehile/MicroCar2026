# 比赛版取消 45° 冲刺（2026-10-22 最新版）

已在现有副本 `code_competition_V字路按搜索_20261022` 中继续修改。比赛版现在全程使用格线路径：直线冲刺 + 搜索普通 90° 转弯；此前单墙 180° 绕行也自然由两个同方向普通 90° 转弯完成。

## 运行行为

比赛版的 `SPURT`、`SPURT_45`、`SPURT_90` 三个状态入口统一进入格线冲刺。使用 `fastway_90()` 生成上下左右的逐格路线，执行器只读取直行、左／右 90° 和必要的普通搜索掉头，运行流程不调用 45° 斜行、45° 出入弯、斜行 90° 或 135° 冲刺动作。

直线保留原有速度上限 `LTopSpeed=140`、末端速度设置 `LBottomSpeed=95` 和 0.7／0.7 加减速系数，使用整数距离计算速度包络。每段直线最后 80 mm 回到搜索定位方式，保留墙沿校正；转弯后的首次直行按原搜索逻辑扣除一次 20 mm 偏移。短直线会按实际距离限制峰值速度。

每个转弯复用现有 `mouseTurnright()` / `mouseTurnleft()` 和搜索曲线。搜索接近速度 30、搜索直线定位速度 80、延迟 9，左右电机 PID 为 13 / 0.74 / 0.9，转弯跟踪 P/D 为 4 / 4。连续左右转弯继续使用原搜索函数针对前一动作的修正。

到终点后按原 90° 运行的 30 mm 停车距离执行减速，随后关停电机并进入 `END`，避免重复规划、重复起跑。路径写入专用的 `FLASH_ADDR_GOPATH_90` 区域，按实际节点数保存。

格线规划增加了邻格边界、不可达终点和路径容量检查，避免原函数首步不沿当前朝向时的未初始化方向问题。最长支持 254 条格线边加 1 个终点节点；更长路线因原计数类型限制会被拒绝。完整路径的节点、方向和开口关系会在运动前核对。
