# 电脑鼠参数名称-功能-调整表（v2.5）

> 仿照课件《电脑鼠参数调整表.pdf》（`../课件/电脑鼠参数调整表.pdf`）的结构编制，
> 并补齐了课件表没有的三列信息：**链路参数名/id**（上位机 `SETQ`/`GET`/`SAVE` 用）、
> **默认值**、**覆写警示**。
>
> **"所在位置"列只写到 文件·函数/变量 级**，不写行号——代码会漂移，函数名不会；
> 检索时在对应文件里搜函数名即可。
>
> ⚠️ **生效范围**：`SETQ`/`GET`/`SAVE` 远程调参只对**远程档**（`MOUSE_REMOTE`）固件生效；
> 按键比赛档的运动代码读编译期常量，不吃参数表（决策记录见 `docs/CHANGELOG.md [2.5.0]`）。
> 未 `SETQ` 过的参数值 == 编译期常量，行为逐位不变。

## 快速用法（上位机）

```bash
cd host
python -m host.cli params get TURNDELAY            # 读
python -m host.cli params setq TURNDELAY 1081344   # 写(Q16.16; 16.5*65536)
python -m host.cli params save                     # 落 Flash page115, 断电保持
```
`python params_write_test.py COM7 --write --strong` 可整表验收（41 项读取 + SETQ + SAVE + 复位往返）。

## 五、课件 21 号 keep_dis —— **跳过（无对应物）**

课件"停转 90° 对齐距离"在当前代码里**没有直接同名对应物**：该功能已被拆解为
`doTaskBefore90Turn` 的墙差 ×0.1 / 陀螺 ×0.6 融合（isr.c）+ `turnDelay` 距离点 +
`POINTTURN90` 的速度阈 15（isr.c）三处分担。造一个新参数等于新设计功能而非参数化，
违背"参数表=暴露已有可调量"的原则，故跳过。若日后做 90° 停转对齐精调，再议。

## 六、覆写与恢复（重要！）

以下参数会被**代码在特定工况下改写**。SETQ 的值在这些工况下会被覆盖——这继承自原比赛代码行为，本轮决策"允许覆写 + 文档警示"：

| 参数 | 覆写点 | 触发工况 | 会恢复吗 |
|---|---|---|---|
| **IRTHRWALL** | motion.c 智能冲刺路径：45° 分支收紧 → 110 | 仅冲刺路径 | ✅ **v2.5 起恢复点改读参数表**（原硬编码 160 会把 SETQ 的值吃掉；现 `LINK_WallThrDefault()` 从参数表取值）。`state.c SpurtTest` 覆写 140 仅按键菜单路径，远程档不触发 |
| TURNP/TURND | spurt.c `SPURT_GainSet*` → 8/5、10/7、4/4 | 仅冲刺路径 | ❌ 不恢复（原代码即如此）。**远程档不进冲刺**（v2.4 决策），不触发 |
| TURNDELAY | spurt.c `SPURT_GainSet90` → 14 | 仅冲刺路径 | ❌ 不恢复；远程档不触发 |
| SPDTURN | spurt.c `SPURT_GainSet90` → 80 | 仅冲刺路径 | ❌ 不恢复；远程档不触发 |
| SPDSEARCH | motion.c 转弯后回落 → 70；45°/90° 分支 → 100/70；冲刺段控制律逐段重算 | **每次转弯后** | 这是控制律的一部分（回落值 70 与初值 95 本来就是两个调校点），本轮决策**只参数化初值**、回落保持 70 |
| speedCfg.fastSprint / accRatio / decRatio / irKp* 等 | 运行时按工况计算 | 各种运动段 | 不在参数表（课件也未列），维持运行变量语义 |
