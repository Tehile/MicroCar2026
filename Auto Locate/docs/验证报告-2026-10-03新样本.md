# 新样本验证报告 —— 2026-10-03 数据

**结论摘要**：在 `samples/` 新增的 36 张实拍上完成验证。算法的**重复性很好**
（同一机位连拍位置极差中位 0.24mm），但本次验证**暴露并修复了一个真实缺陷**：
`geometry.vertex_margin_weight` 默认值偏低导致内顶点误选，使定位在 15/18 帧上
偏 10~45mm。修复后（v1.0.1）跨机位位置最大偏差由 **7.17mm 降到 0.99mm**，
模型正方形与场地边界红胶带的贴合度由 **21.9mm 降到 3.5mm**。

## 2. 验证方法

本批数据**没有测绘真值**（手持俯拍、无标定靶），因此用**互相独立的六类证据**定量刻画，
而不是给一个"误差 xx mm"的空头数字。

| 编号 | 证据 | 为什么它可信 |
| --- | --- | --- |
| A | 有效性 / 失效原因 | 直接可数 |
| B | 内部几何自洽：角标记映射回场地系后必须仍是正方形 | 只用"标记是正方形"这一条与场地约定无关的事实 |
| C | 单应畸变：4 个角标记**实物同尺寸**，映射后尺寸的离散度 | 同上，且天然带量纲 |
| D | 跨机位不变性：换算到锚定在角标记 ID + 排布上的规范系后，同一物理位姿的多帧必须重合 | 重复性 ≠ 准确性，但能抓出随机错误 |
| E | 内顶点组合敏感性：选错会偏多少 | 量化最弱环节的风险敞口 |
| F | 备选判据对照 | 防止"修一个坏一个" |
| **G** | **外部物理参照 ①：模型正方形必须与场地边界红胶带四边贴合、平行** | 独立于算法自身假设的绝对参照 |
| **H** | **外部物理参照 ②：迷宫墙必须落在场地系的 `k/8` 格线上** | 同上，且覆盖整个场地 |

> **关键教训**：A~F（自洽性、重复性）在缺陷存在时**全部表现良好** —— 因为误选内顶点是
> **系统性**的，同一机位连拍会稳定地错在同一个地方，帧间一致性完全看不出来。
> 只有 G、H 这类**外部绝对参照**才能发现它。凡"精度"宣称，必须要有脱离算法自身假设的参照。

## 4. 发现并修复的缺陷：内顶点误选

### 4.1 现象

用 1.0.0 默认配置跑本批数据时：

- 0 号标记位置在**同一机位连拍**的帧间跳动 **9.6mm**（同簇其它机位只有 ~0.2mm）；
- 对比"物理上正确的内顶点组合"，位置偏 **中位 11.9mm、最大 38.2mm**；
- 模型正方形与场地边界红胶带的四边偏移极差达 **中位 21.9mm、最大 47.7mm**。

### 4.2 证据链（四条独立证据指向同一结论）

1. **目视角点**：把每个角标记的 4 个角点高倍放大（`docs/figures/idcorners_163808.jpg`），
   压在红胶带场角上的**都是各标记的 0 号角点** → 正确组合是 `(0,0,0,0)`。
2. **标记对称性**：四个角标记的内侧角点都在场角、身体都朝外，因此映射回场地系后，
   四个中心相对各自场角的**外偏量应当相同**。正确解残差 0.0017~0.0020，
   1.0.0 选中的解 0.0142~0.0152（差 8×）。
3. **场地边界贴合**：见 §3 的 [G]。
4. **迷宫格线对齐**：见 §3 的 [H]。

同时 `docs/figures/beforeafter_163809.jpg` 给出了同一帧的正射对比图：
**1.0.0 的正射图里迷宫是歪的、墙与 1/8 格线对不上；1.0.1 的完全对齐。**

### 4.3 根因

`geometry.select_inner_vertices` 的代价函数：

```
cost = mean(相对形状残差)  +  vertex_margin_weight × mean(顶点距离余量惩罚)
        └── 辅助 ──┘                └──────── 主力 ────────┘
```

- **距离余量项是对的**：正确组合恒为 0.000，次优 0.086 —— 量级正常。
- **形状残差项是退化的**：4 个点唯一确定一个单应，所以各组合之间只差 ~1e-4
  （实测 0.02996 vs 0.03310）。更糟的是它本质上是"用候选自己定的（可能是错的）
  正方形去拟合"，错误组合反而可能把它压低 —— 典型**过拟合**。
- 两项量级差 3 个数量级，于是权重成了生死线：
  `0.02 × 0.0856 = 0.0017 < 0.0031`（形状项差）→ **选了错的**。

实测阈值在 **0.028** 附近 —— 默认值 0.02 刚好落在错误的这一侧。

### 4.4 修复

`geometry.vertex_margin_weight` 默认 `0.02 → 0.1`，建议范围收紧为 `0.05 ~ 0.5`。

实测各权重下"四边偏移极差"（越小越好）：

| 权重 | 0.02 | 0.05 | 0.1 | 0.2 | 0.5 | `nearest` 模式 |
| --- | --- | --- | --- | --- | --- | --- |
| 中位 | 22.3 | 3.8 | 3.8 | 3.8 | 3.8 | 3.8 |
| 最大 | 47.7 | 4.2 | 4.2 | 4.2 | 4.2 | 4.2 |

**0.05 以上与 `nearest` 模式完全一致**，所以取 0.1（离边界有余量）。

## 5. 已否决的备选判据（记录在案，勿再尝试）

| 判据 | 为什么否决 |
| --- | --- |
| **四个角标记映射尺寸一致性最好**（`size_cv` 最小） | 能把尺寸分散度从 3.5% 压到 1.3%，但给出的组合**跨帧不自洽**——同一机位连拍会来回跳，位置差中位 24mm。属过拟合。与正确解一致率 0/28。 |
| **角标记中心必须在场地外（两个坐标都越界）** | 在标记被旋转摆放时该条件不成立，会漏判。 |
| **靠红胶带凸包拟合场地四边形** | 场内墙顶也铺红胶带、且场外有红色杂物，凸包被污染，拟合出的四边形边长 1758/2662/1678/1850px，根本不是一个正方形。 |

**结论**：「离场地中心最近的那个角就是内侧角」是唯一稳健的主力判据，
其余只能当辅助或干脆不用。

## 6. 待现场确认：绝对尺度

算法把角标记边长当作**自由量**与单应一起解（`refine_homography`：8 个单应参数 +
4 个转角 + 4 个边长 = 16 个未知量 / 32 个残差）。实测拟合回来的边长是
**0.03125 场地单位**，在 `FIELD_MM = 1440mm` 下等于 **≈45mm**。

而 `4x4_1000-*.svg` 是 `viewBox="0 0 6 6"` + `width="50mm"`，黑色方块（1 模块黑边框 +
4×4 数据区）**边长就是 50mm**。同时在正射图上，迷宫格距恰好是模型边长的 **1/8**。

三者放在一起：

| 假设 | 推出 |
| --- | --- |
| 格距 = 180mm（现场实测） | 打印被缩到 **90%**（45mm），场地 1440mm |
| 标记 = 50mm（SVG 标称、1:1 打印） | 格距 **200mm**，场地 **1600mm** |

**归一化输出完全不受影响** —— 全流程不使用绝对尺寸，这个差异只影响
`field_size_mm` 换算出的毫米数与打印设置。但文档里"1.0 = 1440mm"的说法需要一次现场复核
（拿尺量格距或角标记黑方块）。

> 顺带修正：README 原写"含 1 模块白边，黑色有效区（4×4）= 33.33mm"有误 ——
> SVG 里 `<rect width="6" height="6" fill="black">` 铺满整个 6×6，黑色区就是 50mm。

## 8. 提出的改进（未实施，待定）

1. **让位置项成为主判据、形状项只作同分裁决**。现在靠权重把两者压在同一个标量上，
   阈值在 0.028 附近，本质上是"用超参掩盖判据退化"。更稳的做法是**字典序**：
   先按 `距离余量` 排序，只在其差值小于噪声带（如 0.01）时才用形状残差裁决。
2. **把 [G]/[H] 这类外部参照做成可选的自检开关**（`geometry.validate_against_boundary`），
   在固定机位比赛场景下每帧或每 N 帧校验一次内顶点选择。
3. **`vertex_margin_weight` 建议值下限从 0.05 起**已在参数层写死，但它是一个"补丁式"
   的安全下界；实现第 1 条后可以撤掉。
