# 整段视频逐帧定位 + 帧间跳变判据（2026-10-28 第二轮）

## 0. 立场修正（本轮的方法论前提）

上一轮我把 `sharp = gap / max(白格极差, 黑格极差)` 当成"合法性判据"，用它拒绝 65/100 帧。
**这个做法不成立**，理由不是阈值高低，而是：

- `sharp` 是本项目**自己拟合**出来的量，标定样本只有 18 个 ArUco 成功帧；
- 用它决定"这一帧算不算数"，等于用我的拟合结果替代事实判定；
- 更直接的证据：f421 这一帧 ArUco 成功、解与真值**完全一致（0.0mm）**，
  但 `margin` 只有 +0.36、`sharp` 在混淆带。按旧判据它会被降级。

**本轮改为**：每一帧都输出一个解，不做接受/拒绝；合法性只由**帧间跳变**判断。
视频前提是"目标一定存在"，那么解序列就应该连续 —— 这比任何单帧打分都更接近物理事实。

## 1. 流水线

| 阶段 | 脚本 | 内容 |
|---|---|---|
| 1 | `vid_stage1_h.py` | 全帧检测四角标记 → 场地单应 `h_<video>.npz` |
| 2 | `vid_stage2_locate.py` | 逐帧格点匹配 → `loc_<video>.json` |
| 3 | `vid_stage3_jump.py` | 帧间跳变分类 → `jump_<video>.json` |
| 4 | `vid_stage4_render.py` | 渲染审阅视频 `review_<video>.mp4` |
| 5 | `vid_stage5_eval.py` | 用外部真值评估跳变判据 |

素材：`samples/VID_20261027_120407.mp4`，592 帧 / 30fps / 4K。

### 1.1 全帧单应
四角齐全 **545/592 = 92.1%**（3 路并行，336s）。缺的 47 帧用时间上最近的有效单应以
逐元素线性插值填补（`hgap` 记录距最近实测帧的帧数）。**这是唯一的"先验"**，且只涉及
几何标定，不涉及目标位置。

### 1.2 加速：两级搜索（`grid_fast.py`）
原版全分辨率 `search_margin` 单帧 32~43s，592 帧不可行。改成：

- **粗搜**：半分辨率（d=10px 整数格距）、全画布、全 β、4 核旋转、2 亚相位 —— 仍是**全局**搜索；
- **细搜**：把粗解当前 K 个种子，在全分辨率上做 β±10°（步长 1°）、±1 格、4 核旋转的局部细化。
  局部块用 `warpAffine` 直接从正射图采样 180×180，不生成 4207² 旋转图、不建 283MB 积分图。

实测：**6.0s/帧 vs 32.4s，5.4 倍**；位置差 **0.4~0.7mm**、margin 差 <0.02。
592 帧 6 路并行 1216s（2.05s/帧）。

> 踩坑：`cv2.warpAffine` 默认把 M 当 **src→dst** 正向变换（内部再求逆），
> 传反向映射必须加 `WARP_INVERSE_MAP`，否则裁剪块全黑（曾得到全 0 的 patch）。
> 另一个坑：局部细化的源必须是**正射图**，用原图会因坐标系不一致而永远采样到零填充区。

### 1.3 θ 标定
θ 不能从 β/rot 推导（OpenCV 旋转角在 y 轴向下时极易弄反）。用 9 个 ArUco 真值帧回归：

```
theta = -beta + 90*rot - 1.02      RMS 1.88°, max 3.39°
```

## 2. 结果

### 2.1 定位精度（44 个 ArUco 精确真值帧）

| 指标 | 值 |
|---|---|
| 误差中位 | **0.6 mm** |
| P90 | 1.4 mm |
| 最大 | 2.0 mm |
| ≤10mm 占比 | **100%** |

### 2.2 跳变统计

阈值 `thr = max(物理 67mm/帧, 统计 med+6·MAD)` = **67 mm/帧**（2m/s @30fps）。

| 判定 | 帧数 |
|---|---|
| ok（与前后帧相容） | 493 |
| shift（分段跳变） | 87 |
| isolated（孤立野值） | 12 |

位移分布：P50 23mm、P90 362mm、P99 1292mm、max 1808mm。
乱帧的解反复吸附在少数几个固定坐标（(0.254,0.609)、(0.587,0.487)、(0.255,0.607) 等），
这些是**墙体结构**，不是卡片。

### 2.3 跳变判据的有效性（外部真值，不是自证）

用"位移 ≤ v_max·Δt + 120mm"判**物理不可能**的帧，这是充分判据、不依赖任何拟合量：

| 指标 | 值 |
|---|---|
| 可判区域（锚点 ±40 帧）覆盖 | 363/592 = **61%** |
| 物理不可能的帧 | 22/592 |
| 其中被跳变判据抓住 | **21/22 = 95%** |
| 判 ok 却物理不可能 | **1/493 = 0.2%** |

## 3. 两次判断失误（必须记录）

1. **f400 我先判定"框套在墙上"** —— 看特写图里是模糊白影 + 红胶带，很像墙面。
   核验后推翻：f395→f422 沿 y≈0.66 匀速直线运动，`f421` 的 ArUco 真值 (0.133,0.664)
   与解 (0.133,0.664) 完全一致，f400 解 (0.520,0.653) 正落在该直线上。
   **那团"白影"是车侧影 + 运动模糊。跳变判据判它 OK 是对的，比我的肉眼可靠。**
2. **`sharp` 当判据** —— 见第 0 节。`margin 0.18` 的帧可以完全正确，
   `margin 0.62` 的帧在同一段里也是正确的，中间没有可分界。

## 4. 局限（必须对用户讲清）

1. **真值只覆盖 61%**。无覆盖区间：f110–175、f296–380、f514–591，共 229 帧
   只有跳变判据、没有外部真值，无法证明对错。
2. **跳变判据的固有盲区**：算法若**连续多帧稳定锁在同一个错误结构上**（如某面墙），
   帧间位移很小，会被判 ok。它只能抓"跳"，抓不了"稳定的错"。
   本轮可判区域内只漏 1 帧（f45），但盲区在原理上存在。
3. **NOH 帧（四角不齐）** 依赖插值 H，f110–175 等段的 hgap 可能较大，位置有系统偏移风险。
4. 单帧 2.05s（6 路并行），非实时。

## 5. 下一步建议

1. **补覆盖**：对 f110–175 / f296–380 / f514–591 三段人工点 10~15 个位置，
   就能把外部真值覆盖从 61% 提到接近 100%，同时给"稳定锁墙"盲区做定量。
2. **稳定错段的自动识别**：若某段整段位置几乎不动（<20mm）但持续 >20 帧，
   与该段前后最近的 ArUco 锚点比对 —— 这是不依赖拟合量的判据。
3. 4K 上直接做"卡片存在性"的连续灰度模板匹配（上一轮已验证位置精度 0.86mm），
   作为格点匹配的第二通道，专门补重模糊帧。
