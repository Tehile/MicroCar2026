### 2.1 V6++ 的五个 Target

| Target | Define | 产物 | 用途 |

| `V6_0mm` | `GOAL_DEPARTURE_EXTRA_MM=0` | `USER/Build/V6_0mm/TEST_V6_0mm.hex` | 终点掉头起步附加 0 mm |
| `V6_2mm` | `=2` | `USER/Build/V6_2mm/...` | 2 mm |

四个比赛档源码完全相同，差异仅来自宏定义。远程档额外启用 `REMOTE_FULL`

这些位置包裹 `#define FLASHSAVE`，启用后额外占用约 9.5 KB RAM。

### 2.3 比赛代码回归判定

判定依据仅为 hex 的 SHA-256，不比较源码 diff 或 ROM 大小。

```bash
cd RemoteControl
python build_v6pp_modes.py                 # 五档全量重编并自动比对 REDLINE
python build_v6pp_modes.py --only Target_Remote
python build_v6pp_modes.py --no-redline    # 仅在计划更新基线时使用
```

执行约定：

1. 比对前须用「改动前源码同机重编」的结果作对照。文档记录的哈希会因源码变更而失效；
   2026-11-05 曾出现「改动源码未重编」导致比赛档误判的情况。
2. UV4 退出码不可靠（0 无错 / 1 仅告警 / 2 有错），判定以构建日志的 `N Error(s)` 为准。
3. `build_competition_modes.py` 不提供 `--help`，误传参数会直接触发全量重编与批量删除护栏；
   日常使用 `--incremental`。

### 3.1 已知失败项

`host/selftest.py --e2e` 在连续拉取后阻塞于 `client.get_all()`，抛出
`CommandError: timeout waiting for: GET ALL`。同一代码在 `pre-release-20261114` 快照的独立 worktree 中复现，
属既有缺陷，与发布整理无关。

- `selftest.py`（纯协议断言）45/45 通过，协议层正常；
- 失败点位于「取流仍在进行时下发 `GET ALL`」，与已知的「取流期间下行受阻」同类，
  参见 [`RemoteControl/docs/工具与校验.md`](../RemoteControl/docs/工具与校验.md)；
- 规避方式：先停流再执行 `GET ALL`，或使用 `link_pull_evt.py`（事件触发、在途恒 ≤ 1）。

## 4. 归档流程

```
验证通过 → 重编并确认 REDLINE 一致 → 审计（git status 干净）→ 更新文档与归档说明
        → git archive 打包 → 抽查 → sha256sum -c → 提交
```

要点：

- 从 git 导出，不从工作区打包。工作区存在未跟踪产物，直接打包无法代表该版本源码。
- 每个 `release/` 目录包含三项：`<包>.zip`、`SHA256SUMS.txt`（含包内各源文件哈希）、`归档说明.md`（版本、日期、提交号、验证范围）。
- 打包与校验分别由 `make_archive.py`、`verify_archive.py` 完成，归档规则变更时需同步修改。

## 5. 未纳入版本控制的内容

判定原则：一次运行即可再生的内容不入库。

| 类别 | 示例 | 原因 |
|---|---|---|
| Python 缓存 | `__pycache__/`、`*.pyc` | 可再生 |
| Keil 中间件 | `USER/Build/`、`USER/Remote/`、`*.o/.d/.crf/.axf/.hex/.map` | Rebuild 即得 |
| Keil 用户状态 | `*.uvgui.*`、`*.uvguix.*`、`JLinkLog.txt` | 仅对本机有效 |
| 运行现场 | `Control/sessions/`、`Control/.tmp/`、`RemoteControl/host/sessions/` | 运行时产生 |
| 采集数据 | `PhoneCamera/pc/data/` | 体量大且随运行增长 |
| 实验产物 | `Auto Locate/out/`、`experiments/` 下大文件 | 可复现 |
| 素材 | `Auto Locate/samples/*.mp4` | 体积 |
| 跑车记录 | `Control/records/` | 数据本体，本地保留 |

例外（必须入库）：`固件_V*/*.hex`、`*.axf`、`SHA256SUMS.txt`、`USER/TEST.uvoptx`。
判定命令：`git check-ignore -v <path>`。
