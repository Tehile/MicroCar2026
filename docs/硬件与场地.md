# 硬件与场地

---

## 1. 场地

| 项 | 值 | 说明 |
|---|---|---|
| 规格 | 8 × 8 格 | 非世赛标准 16 × 16，2026-09-25 现场确认 |
| 格距 | 180 mm | |
| 场地边长 | 1440 mm | 8 × 180 |
| 墙高 | 50 mm | 角标记与墙顶齐平 |
| 顶面 | 白色哑光 | 反光会削弱 ArUco 角点精化 |

场地尺寸在两处配置中出现，必须保持一致：`Control/config.yaml::arena`（轨迹背景网格）与
`Auto Locate/config.yaml::field.field_size_mm`（解算真值），当前均为 `1440.0`。
仅修改一处会导致轨迹缩放错误。

### 1.1 标记布局

| 标记 | ID | 字典 | 位置 | 高度 |
|---|---|---|---|---|
| 角标记 × 4 | 1 / 2 / 3 / 4 | `DICT_4X4_1000` | 场地四角 | 50 mm（与墙顶齐平） |
| 目标标记 | 0 | `DICT_4X4_1000` | 车顶 | 23 mm |

角标记的朝向与 ID 排列顺序均不固定，解算时自动识别四角并按几何关系建立场地坐标系。
四个 ID 必须齐全，缺失任一角标记将返回 `missing_corner`。

标记 SVG 位于 `Auto Locate/4x4_1000-{0..4}.svg`。打印尺寸对应 `config.yaml::gridmatch.card_mm`（46 mm）；
若按角标记实际尺寸缩放，须同步修改该参数，否则格点匹配通道的尺度失配。

### 1.2 差高视差

角标记位于 50 mm、目标标记位于 23 mm，单应变换只对「角标记所在平面」精确。
目标低于该平面 27 mm，结果会沿天底点方向按 `k = (Hc − h_target) / (Hc − h_corner)` 产生位似缩放。
相机居中俯拍时修正量约为场地边长的 1%（≈ 14 mm），未修正的数据不能用于位置反馈控制。

`aruco_locator/parallax.py` 负责该项修正，需要 `camera_height_mm` 与天底点像素坐标。
参数不全时，会话结果标记 `parallax_uncalibrated`，不会静默输出错误数值。

## 2. 车体

| 部分 | 配置 |
|---|---|
| 主控 | STM32F103RB，Keil MDK / ARMCC V5.06 / C90 |
| 运动 | 双直流电机 + 编码器测距，`setvl` / `setvr` 输出 PWM |
| 感知 | 8 路红外（左/右/前左/前右各两档）+ 陀螺仪 |
| 存储 | Flash page115 存远程参数（`SAVE` 掉电保留）；另有飞行记录页（`FLASHSAVE`，远程档关闭以节省约 9.5 KB RAM） |
| 指示 | 4 个 LED；待命基线为 `[0,1,0,0]`，led2 为状态灯会闪烁 |

约束：

- 上电时车体必须静止。陀螺零偏标定为阻塞流程，运动状态下上电会导致标定失败。
- 比赛档 RAM 使用 20 360 / 20 480 B，余量 120 B；新增功能前先核对
  [`docs/版本与发布.md`](版本与发布.md#22-红线基线) 的资源表。

## 3. PC 侧接线

| 项 | 值 |
|---|---|
| 物理层 | USB 转 TTL（CH340）或蓝牙 SPP 模块 |
| 串口参数 | 115200 8-N-1，命令严格停等（在途 ≤ 1） |
| 端口 | 由系统分配（示例 `COM7`）；蓝牙配对后生成「传出」COM 口 |
| 模拟器 | `tcp://127.0.0.1:5555`（`python -m host.sim.mouse_sim`） |

容量：`RTT ≈ 300 ms`（PC 侧 CH340），帧率 ≈ N / RTT。`N=4` 约 13.1 Hz、`N=5` 约 17.0 Hz 为安全上限；
`N=6` 会在十余秒内饱和透传模块，只能断电恢复。

### 3.1 串口静默的三种成因

| 现象 | 原因 | 处理 |
|---|---|---|
| COM 可打开但收不到字节 | 透传模块被灌满 | 断电复位 |
| 烧录成功但串口静默 | USART1 NVIC 未使能 | 改用远程档固件；`LINK_Init` 须显式写 `ISER` |
| 无 `PONG` 且车体自转 | 上电时陀螺标定失败 | 静止状态下重新上电 |

## 4. 相机与拍摄

| 用途 | 建议 | 说明 |
|---|---|---|
| 离线定位（主路） | 手机 4K 视频，固定机位或手持俯拍 | 无标定单应，不要求内参；滚动角不宜接近 ±45°，该姿态存在轴歧义退化 |
| 构图 | 场地占画面 60% 以上，四角标记完整入画 | 缺角直接返回 `missing_corner` |
| 手机实时流（已下线） | 1920 × 1440，纯 Y 平面，2 764 800 B/帧 | 见 `PhoneCamera/` |

`detection.scales=[1,2,3]` 为 720p 与 4K 通用默认值：调小会漏检，调大会增加耗时。

## 5. 现场清单

- 电脑鼠整车、备用电池（发车前低于 7000 mV 将被拒绝发车）
- USB 转 TTL 线（CH340）或蓝牙 SPP 模块
- J-Link（烧录、`fromelf` 查符号）
- 卷尺（测量场地与镜头高度）、哑光白布（垫标记）
- 打印完成的 5 个 ArUco 标记及支撑件（保证角标记与墙顶齐平）
