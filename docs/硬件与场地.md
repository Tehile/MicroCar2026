# 硬件与场地

---

## 1. 场地

| 项 | 值 | 备注 |
|---|---|---|
| 规格 | **8 × 8 格** | **不是**世赛标准的 16×16；2026-09-25 现场确认 |
| 格距 | 180 mm | |
| 场地边长 | 1440 mm | 8 × 180 |
| 墙高 | 50 mm | 四角标记与墙顶齐平 |
| 顶面 | 白色哑光 | 反光会让 ArUco 角点精化退化 |

> `Control/config.yaml::arena` 与 `Auto Locate/config.yaml::field.field_size_mm` 必须一致（现在都是 1440.0）。
> 前者只用来画轨迹背景网格，后者是解算真值——改一处不改另一处，轨迹就会缩放错。

### 1.1 标记布局

| 标记 | ID | 字典 | 位置 | 高度 |
|---|---|---|---|---|
| 角标记 ×4 | 1 / 2 / 3 / 4 | `DICT_4X4_1000` | 场地四角 | 50 mm（= 墙顶） |
| 目标标记 | 0 | 同字典 | 装在小车顶上 | 23 mm |

**角标记的朝向与 ID 排列顺序都不固定**——代码自动识别四个角、按几何关系建立场地坐标系，
所以贴的时候不需要"按顺序贴"，但**四个 ID 必须齐**，缺一个就解不出来（`missing_corner`）。

标记 SVG 在 `Auto Locate/4x4_1000-{0..4}.svg`，打印后边长按 `config.yaml::gridmatch.card_mm`（46 mm）
或按角标记实际尺寸等比缩放——**缩放了就要改配置**，否则格点匹配通道的尺度对不上。

### 1.2 差高视差

角标记在 50 mm、目标在 23 mm，单应只对"角标记所在的平面"精确。
目标低 27 mm ⇒ 结果会沿**天底点方向**被位似缩放 `k = (Hc − h_target)/(Hc − h_corner)`。
相机居中俯拍时修正量约 **1% 场地边长**（≈14 mm），不修就不能拿去做闭环。

`parallax.py` 负责这件事，需要 `camera_height_mm` 与天底点像素坐标；参数不全时
会话会带 `parallax_uncalibrated` 标志而不是静默给错数。

## 2. 小车

| 部分 | 说明 |
|---|---|
| 主控 | STM32F103RB（Keil MDK / ARMCC V5.06 / C90） |
| 运动 | 双直流电机 + 编码器测距，`setvl/setvr` 走 PWM |
| 感知 | 8 路红外（左/右/前左/前右各两档）+ 陀螺仪 |
| 存储 | Flash page115 存远程参数（`SAVE` 掉电保留）、另一页存飞行记录（`FLASHSAVE`，远程档**刻意关闭**以省 9.5 KB RAM） |
| 指示 | 4 个 LED。**待命基线是 `[0,1,0,0]`**——led2 是状态灯会闪，不要要求全 0 |

> ⚠️ **上电必须静止**：陀螺零偏标定是阻塞死循环，车在动就永久自旋。
> ⚠️ **RAM 本就近满**（比赛档 20 360 / 20 480 B）。要加功能先看 `docs/版本与发布.md` 的资源表。

## 3. 电脑侧接线

| 项 | 值 |
|---|---|
| 物理层 | USB 转 TTL（CH340）或蓝牙 SPP 模块 |
| 串口参数 | **115200** 8-N-1，命令严格停等（在途 ≤ 1） |
| 本机端口 | `COM7`（其它机器在界面里点【刷新】选） |
| 蓝牙 | Windows 配对后会生成一个"传出"COM 口；界面里带 `[蓝牙]` 标记 |
| 模拟器 | `tcp://127.0.0.1:5555`（`python -m host.sim.mouse_sim`） |

**容量顶**：`RTT ≈ 300 ms`（全在 PC 侧 CH340 上），帧率 ≈ N / RTT。
`N=4` → 13.1 Hz，`N=5` → 17.0 Hz 是安全顶，**`N=6` 十几秒把透传模块灌死，须物理断电**。

### 三种"全静默"要分清

| 现象 | 原因 | 处理 |
|---|---|---|
| COM 能开但 0 字节 | 模块被灌满 | 断电复位 |
| 烧录成功但串口全静默 | USART1 NVIC 没开 | 换远程档固件；`LINK_Init` 必须显式写 `ISER` |
| 无 PONG、车在转 | 上电陀螺标定自旋 | 静止上电 |

## 4. 相机

| 用途 | 建议 | 说明 |
|---|---|---|
| 离线定位（主路） | 手机 4K 视频，固定机位或手持俯拍 | 无标定单应，不要求内参；但**滚动角别接近 ±45°**（轴歧义固有退化） |
| 图像摆位 | 场地占画面 60% 以上，四角标记完整入画 | 缺角直接 `missing_corner` |
| 手机实时流（已下线） | 1920×1440，纯 Y 平面，2.76 MB/帧 | 见 `PhoneCamera/` |

`Auto Locate` 的 `detection.scales=[1,2,3]` 是 720p/4K 都能用的默认；调小会漏检，调大会慢。

## 5. 控制器与线材清单（现场带的东西）

- 电脑鼠整车 + 备用电池（**发车前 < 7000 mV 会被拒绝发车**）
- USB 转 TTL 线（CH340）／蓝牙 SPP 模块
- J-Link（烧录 + `fromelf` 查符号）
- 卷尺（量场地与镜头高度）、A4 白纸/哑光布（垫标记）
- 打印好的 5 个 ArUco 标记 + 支撑件（保证角标记与墙顶齐平）
